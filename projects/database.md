# Database Extension for EMC2: Parameter Variability Across Open-Access Datasets

> **Level:** MSc  
> **Duration:** 3–6 months  
> **Keywords:** `cognitive modelling`, `decision making`, `reinforcement learning`, `parameter estimation`, `open science`

---

## Description

Cognitive modelling research on decision making and reinforcement learning typically relies on one or two datasets per study. This makes it difficult to assess how robust model parameters are across different experimental contexts, populations, and paradigms. At the same time, truly open-access datasets in this field remain scarce.

This project addresses both problems. In the first phase, the student collects and curates open-access datasets relevant to decision making and reinforcement learning, documenting proper metadata for each. In the second phase, the student leverages recent advances in fast and rigorous Bayesian parameter estimation — implemented in the EMC2 package — to analyse to what extent parameters vary between datasets that supposedly measure the same cognitive phenomenon.

## Goal

To build a curated, well-documented database of open-access datasets compatible with EMC2, and to characterise between-dataset variability in both baseline model parameters and the effects of common experimental manipulations.

## Required Knowledge
